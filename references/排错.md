# 排错

环境和安装见 安装.md，先跑 `python -I scripts/doctor.py`。

**不要用 librosa**：Windows 上 numba 常让进程直接崩（access violation）。本 skill 的分析只用 numpy / scipy。

## 常见报错

| 现象 | 原因 | 办法 |
|---|---|---|
| `UnicodeDecodeError` / `gbk codec` | Windows 默认编码 | 设 `PYTHONUTF8=1` 再跑 |
| song.md 写「没有强制对齐」 | 没装 torch + transformers，或没分出人声 | 见安装.md；分轨用 `--demucs` 或 `--stems` |
| 「对齐结果和 LRC 差 N 秒」 | 网上的 LRC 时间不准（常见），或歌词和唱的不一样 | 差几秒以内用对齐的；整段错开就检查歌词有没有漏写重复的句子 |
| 纯文本歌词报「超过 5 分钟」 | 对齐模型一次最多 5 分钟 | 给带时间的 LRC，或先截一段 |
| `页面出错了：……` | scene.js / cues.json 写错 | 报错信息里有行号；`看不懂的时间` = 时间写法不对；`镜头用了画面 "xx"，shots 里没有` = 名字对不上 |
| 字变成方框 / 缺字 | GB2312 子集没有这个字 | 那句换 `DouyinSans`（全字库），或者给生僻字单独指定字体 |
| 静帧全黑 | 镜头函数里 `ctx.setTransform(1,0,0,1,0,0)` 把缩放清掉了 / 画到了画布外 | 用 `ctx.save()` / `restore()`，别重设变换；真要回到原点用 `M.resetTransform(ctx)`（草稿是半分辨率，直接 setTransform(1,…) 会画错） |
| 渲染很慢（一帧 > 100ms） | 每帧重画静态内容、getImageData、大 blur | 见画面库.md「性能」 |
| 成片在某些播放器里发黑 / 发灰 | 色彩范围不对 | render.py 已经输出 BT.709 电视范围，不要自己改编码参数 |
| 审片说歌词没上屏，其实画了 | `mode: scene` 自己画但没调 `M.logLyric` | 加上 |
| 拍子差半拍 | 没分轨、混音里军鼓和镲太响 | 先分轨（`--stems` / `--demucs`），或 `--bpm` 给个大概速度 |

## 浏览器里预览

项目里跑 `python -m http.server 8000`，开 `http://localhost:8000/`：空格播放、←→ 跳小节、D 显示节拍信息（第几小节、哪个镜头、大时刻）。直接双击 index.html（file://）读不了 json。
