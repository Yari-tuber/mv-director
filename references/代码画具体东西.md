# 用代码画出歌词里的东西：人、动物、房子、天气、光、物件、动作

这个 skill 的画面**全部用代码画**（canvas），不用生图、不用照片和网图。

难点不在画得多精细，而在**画得出歌词说的东西，而且一眼认得出**。先选一种代码画得好、又认得清的画风，再把每句的名词、动作做成「会动的零件」。

## 先选好画的风格（决定了你画得出什么）

| 风格 | 为什么代码画得好 | 适合 |
|---|---|---|
| **剪影 / 剪纸 / 皮影** | 人和物都是一块颜色的剪影，靠轮廓认东西；关节拼起来就能动 | 讲故事、有人物的歌 |
| 水墨写意 | 笔触、晕染、留白；人和动物用几笔剪影加飞白 | 古风、山水、抒情 |
| 漫画 / 波普 | 粗黑线平涂、网点、对白框、速度线 | 搞笑、网络梗、热血 |
| 像素 | 方格就是画面，小人小物好画 | 游戏感、复古 |
| 扁平插画 | 圆角几何拼人和物，平涂 + 少量阴影 | 都市、日常、可爱 |
| 几何 / 线条 | 抽象图形 + 字 | 电子乐、纯音乐 |

先看歌讲什么、是什么年代和情绪，再挑风格。也可以借别的 skill 的画风（接画风.md），在 plan.md 写清为什么选它。

人物的身份、情绪靠这几样表达，不靠五官细节：
- **轮廓**：发型、帽子、衣服下摆、背的东西；
- **姿势**：垂头、仰头、张开双臂、蜷缩、奔跑；
- **道具**：伞、书包、吉他、手机；
- **镜头**：远景显得渺小，特写显得紧张，仰拍显得强大。

## 关节剪影：人和动物怎么画、怎么动

参考 `参考代码/剪纸木偶/puppets.js`，读懂思路，再写成适合你这首歌的版本。

- **身体 = 一串关节**：骨盆 → 躯干 → 脖子 → 头；肩 → 上臂 → 前臂 → 手；胯 → 大腿 → 小腿 → 脚。
  - 每段用 taper（两头粗细不同的圆头线段）画；
  - 整个人用同一个颜色填，就是剪影。
- **姿势 = 一组关节角度**：站、走、跑、坐、跪、伸手、拥抱、转身、倒下……写成关键帧。
  - 姿势之间按时间插值；
  - 走、跑是正弦循环（`walkLegs`）；
  - 手要够到某个点用两段 IK（`ik2`）。
- **四条腿的动物**：一样的关节链，腿多一节，躯干是椭圆加脖子；跑的时候四条腿错开相位。
- **头发、衣角、围巾、旗子**：从固定点往外的多边形，用风和时间让末端飘（`phair`、`scarf`）。变老、变色就是同一个形状换颜色。
- **画一次就缓存**：不动的东西（房子、山、背景）画到离屏画布（`M.cached`），每帧只 `drawImage`；会动的人每帧重算关节，很便宜。

## 场景零件：按歌词里的名词一样一样做

写完逐句分镜以后，把每句 `keys` 和 `see` 里要出现的东西列成清单，每样写成一个函数，比如：
- `person(ctx, x, y, s, pose, t)`
- `house(ctx, x, y, s, lightsOn)`
- `rain(ctx, t, strength)`

同一样东西在不同句子里换大小、位置、角度、状态，就是新镜头。

| 歌词里常见的 | 代码怎么画 |
|---|---|
| 人（主角、你、人群） | 关节剪影；人群 = 同一个函数，位置和动作相位用 `M.hash` 打散 |
| 动物 | 关节剪影；鸟群用小 V 形在曲线上飞 |
| 房子、街、城市、窗、桥 | 矩形 + 屋顶 + 窗洞；一层层排出纵深；窗灯是会亮会灭的小矩形 |
| 山、海、树、月、云 | 多层剪影（远淡近深）；海浪是正弦曲线；树是递归分叉 |
| 雨、雪、风、花瓣、火星 | `M.particles(ctx, 'rain' / 'snow' / 'dust' / 'petals' / 'embers')`，或自己写粒子 |
| 灯、火、星、烟花 | 发光圆（径向渐变 + `lighter` 叠加）；烟花用 `M.particles(ctx, 'fireworks', {at: 'line3@某个词'})` |
| 物件（信、杯子、手机、钥匙） | 简单几何 + 最能认出它的那个特征；用特写镜头 |
| 动作（离开、奔跑、拥抱、伸手、坠落） | 姿势关键帧 + 位移；「离开」= 转身、走远、变小 |
| 变化（变老、天亮、下雨、心碎） | 同一个东西随时间变颜色、形状、大小，卡在关键词上 |
| 抽象情绪（孤独、勇敢、想念） | 用一个具体处境演出来（读懂歌词.md） |

## 镜头和节奏

- **一句一个构图**：远景、中景、特写、俯、仰换着来。
- **关键词那一刻兑现**：画面变化写 `M.word(3, '某个词')`，或者卡点表 `line3@某个词`。
- **拍子分层**：小节头换构图或推镜头，底鼓让脚落地、东西一震，军鼓让光一闪。

## 自查

`render.py <项目> lines` 每句关键词那一刻出一张图。遮住歌词：
- 认不出是什么东西 → 轮廓不对，加最有代表性的特征；
- 认出来了但看不出在干嘛 → 姿势不对，动作要大、要夸张。
