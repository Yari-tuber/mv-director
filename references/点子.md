# 点子：把逐句画面串成一个故事

**先读 读懂歌词.md。** 点子不能代替逐句演出：每一句歌词唱的时候，画面都要演它在说什么。点子是把这些画面串起来的那根线：同一个主角、一个会变化的母题、一条情绪线，让观众觉得这是一个故事，而不是一页页插图。

做坏过的样子：抓住一个好看的意象（一只手、一个圆）从头画到尾，歌词贴在上面。看着精致，但观众会觉得「没有表现出歌词想要展示的内容」。
## 四步把逐句画面串起来

1. **歌词表面在说什么**：一句话。
2. **底下是什么**：情绪、梗、反差、自嘲、讽刺。网络梗歌、口头禅歌要找到那个梗本身；抒情歌找那个画面化的情绪。
3. **选一台「视觉发动机」**：一个可以随着歌一路**升级**的东西（下面的套路）。它就是母题。
4. **把歌的结构对到故事上**：
   - 主歌 = 交代（母题第一次出现，小、安静）；
   - 铺垫 = 憋（母题开始失控、加速、变多）；
   - 抽鼓 = 屏住呼吸（只剩母题本身，定住）；
   - 副歌 = 兑现（母题变形 / 爆开 / 吞掉一切）；
   - 桥段 = 反转（换个角度看母题，世界翻面）；
   - 最后一次副歌 = 最大的一次升级。

## 视觉发动机（套路，挑一个做主、最多再配一个）

| 套路 | 做法 | 副歌那一下 |
|---|---|---|
| 字面化 | 把歌词里的比喻、梗按字面画出来 | 比喻成真，而且大到离谱 |
| 尺度升级 | 一样东西每段大一级：桌面 → 房间 → 城市 → 星球 | 镜头猛拉远，发现它已经比世界大 |
| 复制增殖 | 一个变两个变满屏（每拍多一个） | 满屏同步动作，或者全部被一下清空 |
| 世界翻面 | 同一场景的两个版本（白天 / 黑夜，正 / 反，真实 / 内心） | 一拍之内翻过去 |
| 物件成角色 | 一个物件（对话框、灯、影子、杯子）有了脾气和动作 | 它造反了 |
| 文字世界 | 场景本身由歌词的字搭成（字是墙、路、雨） | 字塌下来 / 炸开重组成新画面 |
| 镜像重复 | 每次重复的歌词，用同一个构图但变一样东西 | 重复第 N 次时整个崩坏 |
| 越界 | 画框、界面、纸面里的东西跑出来 | 打破第四面墙 |

## 检查（每条都要过）

- [ ] 一句话能说清，没听过歌的人能想象出副歌那一下。
- [ ] 母题在**每一段**都在，而且每段长得不一样（在升级）。
- [ ] 大时刻写的是「画面本身怎么变」，不是「闪白 + 震动」。
- [ ] 金句（hook）每次出现都比上次更猛。
- [ ] 主歌是收着的。全程都满，副歌就没有高潮。
- [ ] 跟画风无关：换一个画风，这个点子照样成立。

## 不要这样

- **画风贴图 + 字幕**：好看的背景在动，歌词在底下一行行过。这就是「什么都没有」的感觉。
- **每段一个毫不相干的场景**：像幻灯片，没有母题，观众记不住。
- **背景在动、主体不变**：动的东西要是观众盯着的那个。
- **所有拍都同样地跳**：节拍器不是 MV。
- **抄例子**：skill 文档里的例子只演示写法；点子要从这首歌里来。
