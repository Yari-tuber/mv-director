# 卡点表 cues.json

## 完整格式

```json
{
  "title": "歌名",
  "concept": "一句话立意（和 plan.md 第 3 节一样）",
  "credit": "Music / Lyrics：某某　Movie：某某",
  "story": "这一段在讲什么：谁、发生了什么、情绪怎么走、在什么时代和地方",
  "board": [
    { "line": 1, "says": "字面在说什么", "see": "画面上具体看到什么：谁、在哪、在干嘛、镜头", "keys": ["歌词里的原词"] }
  ],
  "look": { "bg": "#101014", "accent": "#ffd400", "vignette": 0.3, "grain": 0.05 },
  "arc": [["bar1", 0.3], ["bar9", 0.2], ["bar12.3", 0.6], ["bar13", 1.0], ["bar21", 0.45], ["end", 0.7]],
  "shots": [
    { "at": 0, "scene": "window", "params": { "open": 0 }, "why": "line1「推开窗」：背影走到窗前推开木窗" },
    { "at": "line1@灯火", "scene": "city_lights", "in": "flash", "why": "唱到「灯火」那一刻，窗外整座城的灯亮起来" },
    { "at": "bar5", "scene": "room", "params": { "zoom": 2 }, "in": "flash", "why": "……" },
    { "at": "bar13", "scene": "burst", "in": "smash", "cam": { "from": { "zoom": 1.2 }, "to": { "zoom": 1 } }, "lyrics": { "mode": "scatter" }, "why": "进副歌：……" }
  ],
  "lyrics": {
    "default": { "mode": "pop", "size": "big", "pos": "lower", "exit": "fade" },
    "lines": { "line8": { "mode": "big", "exit": "shatter" } }
  },
  "moments": [
    { "at": "bar13", "name": "副歌炸开", "big": true, "fx": ["flash", "punch", "shake"], "what": "画面本身发生了什么" },
    { "at": "bar12.3", "name": "抽鼓", "fx": [{ "fx": "freeze", "dur": 2 }] }
  ],
  "rules": [
    { "on": "bar", "fx": "punch", "amt": 0.03, "from": "bar13", "to": "bar21" },
    { "on": "kick", "fx": "shake", "amt": 5, "from": "bar17", "to": "bar21", "every": 2 }
  ]
}
```

## 时间写法

`0`、`12.5`（片内秒）· `bar9`（第 9 小节第 1 拍）· `bar9.3`（第 9 小节第 3 拍）· `line8`（第 8 句开唱）· `line8@灯火`（第 8 句唱到「灯火」那一刻，逐字对齐来的）· `line8@end`（第 8 句唱完）· `beat40`（第 40 拍）· `end`。

后面可以加偏移：`+0.5b`（拍）、`-0.1s`（秒）、`+1bar`。小节号、句号看 song.md（片内第一个小节头 = bar1，之前的弱起 = bar0）。

## 各部分怎么写

- **story / board**：读懂歌词的结果（见读懂歌词.md）。
  - board 每一句都要有：`says` 字面、`see` 画面、`keys` 要演出来的原词；
  - cue_lint 会查：每句都有、keys 是原词、唱这句时画面换了、关键词上有动作。
- **画面全部代码画**：不用 images、不用 photo 镜头（cue_lint 会报错）。

- **shots**：一个镜头 = 一段用同一个画面函数的时间，到下一个镜头的 at 为止。
  - 切点落在小节头（bar9）；故意切在拍上（bar9.3）写 `"offbeat": true`。
  - 超过 4 小节不换要有理由，超过 8 小节写 `"hold": true`，并在画面里安排变化。
  - `why` 写「这句唱什么，所以画什么」。
- **moments**：
  - `big: true` 的是大时刻，必须写 `what`（画面本身怎么变），至少 3 个；音乐上的大时刻候选（song.md 分 ≥ 0.9 的）每个都要有。
  - 非 big 的是小时刻：定格、反色、一下推镜头。
- **lyrics**：
  - `default` → `shots[].lyrics`（这个镜头里开唱的句子）→ `lines.lineN`，后面的覆盖前面的。
  - 字号至少 mid（108px）。
- **arc**：计划的强度，0..1，点之间平滑过渡。rules 的特效会按它缩放，审片会量画面跟不跟它。
- **rules**：在一段时间里每个 bar / beat / kick… 自动加一个小特效。
  - `every: 2` 隔一个打一次；`offset: 1` 从第二个开始。
  - 别一条规则盖全片，按段落分开写。

## 节奏套路（149 BPM 这种快歌：一拍 0.4 秒，一小节 1.6 秒）

| 段落 | 换镜头 | 拍上 | 歌词 | 特效 |
|---|---|---|---|---|
| 主歌 | 2–4 小节一换，镜头里慢推 | 元素轻轻脉动（kick decay .12，幅度小） | pop / karaoke / type，位置固定 | 几乎不用 |
| 铺垫 | 1–2 小节一换，越来越快 | 跟拍收紧、加速、缩小、变暗 | slam / stack | 最后一小节加 pre 蓄力 |
| 抽鼓 / 断拍 | 不切，定格或黑场 | 全停，只留一样东西 | 只留一个字或一句 | freeze / blackout |
| 副歌第一拍 | 硬切或 smash | | big / stamp / stack | flash + punch + shake（+ rgb） |
| 副歌 | 每小节一换，或一个镜头里每小节变一次 | 底鼓弹、小节头推 | scatter / slam / bubble | rules：bar → punch .03 |
| 桥段 / 转折 | 突然换世界（反色、换场景） | 放慢 | type / chat / karaoke | invert / glitch 一次 |
| 最后一句 | 回到母题 | 收 | 和开头呼应 | 慢推 drift |

注意：表里是起点，不是答案。点子决定一切：同样是副歌，「影子走下墙」和「城市被淹没」需要的切法完全不同。
