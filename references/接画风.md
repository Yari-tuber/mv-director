# 接画风：从风格库借一种画风

分工：
- **风格库**管「长什么样」：色板、线条、材质、镜头语言、动作节奏；
- **mv-director** 管「演什么、什么时候发生、发生得多大」：歌词内容、分镜、卡点。

点子、故事、每一句的画面都是你读懂这首歌以后自己构思的。**不要用风格库自己的整片流程和渲染器**，它们大多不分析你的歌，做出来就是「好看但不跟拍、不演歌词」。

## 第一步：翻风格库、和用户确定

风格库可以是任何仓库或 skill：一个画风一个文件夹、一个画风一份说明、一张画风总表，各家组织方式不一样。

1. **先读它的 README 和索引**（总表、目录页、catalog），弄清楚三件事：
   - 一共有哪些画风；
   - 每个画风的说明写在哪；
   - 有没有样片源码、样张图。
2. **列出全部画风**：名字 + 一句话，按它自己的分类。
3. **推荐 3–5 个最配这首歌的**，每个一句为什么（年代、情绪对得上；画得出歌词里要画的东西）。
4. **问用户要哪个**，等回答。用户已经说了，或者说「你定」，就不用问。

## 第二步：读懂这个画风，写成「画风卡」

读这个画风的说明，再翻样片源码看它是怎么画出来的。把下面这些抄进 plan.md 的「画风卡」，写具体的值，不写形容词：

| 项 | 写什么 |
|---|---|
| 色板 | 具体色值，主色、点缀色各是什么、各占多少 |
| 材质 | 纸、墨、布、胶片颗粒、网点、像素……怎么用代码做（createPattern、噪声、离屏缓存） |
| 线条和形 | 粗细、有没有描边、边缘硬还是虚、形是几何的还是手绘抖动的 |
| 人和物怎么画 | 剪影 / 线描 / 平涂 / 体块；人物比例；关节怎么动 |
| 镜头语言 | 推拉摇移还是固定机位、景别习惯、转场方式 |
| 动作节奏 | 顺滑还是一顿一顿（定格感）、帧率感、弹性 |
| 字 | 歌词用什么字体和排法才合这个画风 |
| 忌讳 | 说明里明确写着「不要」的 |

画风卡写完，后面每个镜头都对照它画。逐句图出来以后，再对照它的样张看对不对味。

## 第三步：在 mv-director 里画

- 用 mv-director 的运行库（`mv/mv.js`）和自己的 scene.js 画，镜头时间用 `s.lt` / `s.p`，节拍用 `M.pulse` 等。
- 样片源码里的**画法函数**（画一种笔触、一种纹理、一种角色关节）可以学着重写。许可允许的话，也可以把小段代码拷进项目：
  - 在文件开头注明出处和许可；
  - 在 NOTES.md 署名。
- 风格库自己的 JS 库要直接用的话，拷进项目 `lib/`，在 index.html 里 `mv/mv.js` 之后、`scene.js` 之前按顺序加载。
- **不搬**它样片里的故事、角色、构图、整段场景。
- **节拍一律用 song.json**：风格库样片里手填的 BPM、节拍表都不要用。

## 两个常见风格库的样子（只是例子，别的库照第一步自己翻）

| | lemo-opuscar（LemoLab，MIT） | huashu-art-motion（花叔 alchaincyf，MIT） |
|---|---|---|
| 仓库 | github.com/lemomo-ai/lemo-opuscar | github.com/alchaincyf/huashu-art-motion |
| 画风总表 | `styles/README.md`（中英文名、分类） | `references/风格配方/` 文件名就是编号和画风 |
| 一个画风 | `styles/<画风>/STYLE.md` 说明、`DEMO.md` 样片怎么做、`demo/` 源码、`poster.jpg` 样张、`style.json` 中英文名和一句话 | `references/风格配方/<编号>_<画风>.md` 配方（管线、母题动画、色板、踩坑）、`scripts/engine/scenes/<同名>.js` 源码 |
| 能直接借的库 | 各样片自带的 js | `scripts/engine/lib/`：`util.js`（`window.U`，最先加载）、`paint.js`（噪声、纹理、手绘线、网点）、`rig.js`（平滑路径、渐细笔画、骨架） |
| 要注意 | 它的样片是「先写节拍表再配乐」，和 MV 方向相反 | 它的 BPM 是手填的，不分析你的歌 |
| 署名 | 「画风参考 LemoLab lemo-opuscar 的 <画风名>（MIT）」 | 「画风参考 花叔 alchaincyf/huashu-art-motion 的 <画风名>（MIT）」 |

## 常见的坑

- 画风库每帧画几千个笔触会很慢：不动的部分放进 `M.cached`，只让会动的东西每帧重画。
- 「手绘线条每隔几帧抖一次」要用时间算：`Math.floor(M.t * 8)` 当种子，不要用帧计数器。
- 网点、纹理用 `createPattern` 铺，别逐像素画。
- 别把风格库的英文标题字、Logo、署名画进你的片子。
