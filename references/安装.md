# 安装

先跑一次 `python -I scripts/doctor.py`，它会告诉你缺什么。

## 必装

| 东西 | 干什么 | 怎么装 |
|---|---|---|
| Python 3.9+ | 跑脚本 | python.org，或系统自带 |
| numpy、scipy、matplotlib、pillow | 听歌拆解、画分析图 | `python -m pip install numpy scipy matplotlib pillow` |
| playwright + Chromium | 用浏览器逐帧渲染 | `python -m pip install playwright`，再 `python -m playwright install chromium`（电脑上有 Chrome 也可以不下；国内慢就先设 `PLAYWRIGHT_DOWNLOAD_HOST=https://registry.npmmirror.com/-/binary/playwright`） |
| ffmpeg | 读音频、合成视频 | Windows：`winget install Gyan.FFmpeg`；macOS：`brew install ffmpeg`；Linux：包管理器 |

## 强烈推荐

| 东西 | 干什么 | 怎么装 |
|---|---|---|
| demucs | 把歌分成鼓、贝斯、人声、其他四轨：拍点从鼓轨找更准，逐字对齐要用人声轨 | `python -m pip install demucs`。第一次运行下载约 80 MB 模型。装在别的 Python 里，就设 `MV_DEMUCS_PY` 指过去 |
| torch + transformers（5.x） | 逐字强制对齐（Qwen3-ForcedAligner，阿里通义，Apache-2.0）：字幕和演唱对到每个字 | `python -m pip install torch transformers`。有 NVIDIA 显卡就装 CUDA 版 torch，快很多；没有也能用 CPU 跑 |

对齐模型第一次用时会自动从 Hugging Face 下载 `Qwen/Qwen3-ForcedAligner-0.6B-hf`（约 1.8 GB）：
- 国内先设 `HF_ENDPOINT=https://hf-mirror.com`；
- 或者自己下好（Hugging Face / ModelScope），设 `MV_ALIGNER_MODEL=<模型文件夹>`；
- torch 和 transformers 装在别的 Python 里（比如一个单独的虚拟环境），设 `MV_ALIGNER_PY=<那个 python>`。

不装对齐：也能做，但只能用 LRC 里的整句时间，字幕不能逐字卡，网上的 LRC 还常差半秒以上。

## 装 skill

把这个文件夹放进你的 agent 能找到 skill 的地方：

- **Codex**：`~/.agents/skills/mv-director/`，或者项目里的 `.agents/skills/mv-director/`；也可以在对话里发「$skill-installer 安装 https://github.com/Yari-tuber/mv-director（SKILL.md 在仓库根目录，安装时用 --path . --name mv-director）」。
- **Claude Code**：`~/.claude/skills/mv-director/`，或者项目里的 `.claude/skills/mv-director/`。
- 装好以后**新开一个对话**，skill 才会生效。

## 风格库（想借画风时）

- **lemo-opuscar**：在你的工作文件夹里 `git clone https://github.com/lemomo-ai/lemo-opuscar`（只借画风的话，不用装它的依赖）。
- **花叔 huashu-art-motion**：按它的 README 装成 skill，或者 `git clone https://github.com/alchaincyf/huashu-art-motion` 到工作文件夹。

不用装它们的依赖：mv-director 只读它们的画风说明和样片源码，用自己的流程和渲染器做。
