# 画面库：scene.js 怎么写（mv.js 运行库）

## 结构

```js
MV.scene({
  bg: '#101014',                       // 每个镜头开画前铺的底色（cues.json look.bg 优先）
  fonts: { Name: 'assets/x.woff' },    // 额外字体（fonts/ 里的已经全部加载，名字见 fonts/字体授权.md）
  images: { paper: 'assets/paper.jpg' },  // 图片：M.img.paper
  async setup(M) { },                  // 只跑一次：缓存静态底图、预先算好路径
  shots: {                             // 卡点表 shots[].scene 引用这里的名字（纯英文标识符）
    chat(ctx, s, M) { ... },
    burst(ctx, s, M) { ... },
  },
  lyricDefault: { font: 'NotoSansSC-900', fill: '#fff', stroke: '#000' },  // 全片歌词默认样子
  glyph(ctx, ch, x, y, px, st, M) { },   // 可选：歌词的一个字怎么画（画风字：网点、金箔、毛笔……）
  post(ctx, M) { },                    // 可选：镜头 + 歌词画完后再叠一层（世界层，跟着镜头晃）
  overlay(ctx, M) { },                 // 可选：最上层（屏幕层：画框、署名、纸纹），不跟镜头晃
  camera(cam, M) { },                  // 可选：每帧改镜头 cam.zoom / cam.x / cam.y / cam.rot
});
```

镜头函数 `(ctx, s, M)`：`ctx` 是 1920×1080 坐标的画布（已经铺好底色，save/restore 包着）。

`s` = `{ id, scene, t 全片秒, lt 镜头内第几秒, p 镜头进度 0..1, dur 镜头长度, t0, t1, params 卡点表里写的参数 }`。

同一个画面函数可以被好几个镜头用，用 `s.params` 区分（`{ "scene": "burst", "params": { "gold": true } }`）。

**画面只由时间决定**：同一个 t 画两遍要一模一样。随机用 `M.hash(i, j)`（0..1）或 `M.rng(种子)`，噪声用 `M.noise(x, y)`。

## 节拍

| 函数 | 返回 | 用法 |
|---|---|---|
| `M.pulse(kind, {decay, pre, weight})` | 0..1：事件那一刻 1，按 decay 秒指数回落 | `scale = 1 + .1 * M.pulse('kick', {decay: .12})` |
| `M.since(kind)` / `M.until(kind)` | 离上一个 / 下一个事件几秒 | 蓄力：`M.until('bar') < .4` |
| `M.count(kind)` | 到现在发生了几次 | 每小节换颜色：`palette[M.count('bar') % 4]` |
| `M.beat()` | `{i, p, t0, len}`，p = 这一拍走了多少 | 摆动：`Math.sin(M.TAU * M.beat().p)` |
| `M.bar()` | `{n 第几小节, beat 第几拍, p, t0, len}` | |
| `M.section()` | `{kind 主歌/铺垫/副歌/桥段/间奏, letter, energy, p}` | 按段落换玩法 |
| `M.env(name)` | 0..1 曲线：`energy` `low` `mid` `high` `onset` | 连续的呼吸、亮度 |
| `M.intensity()` | 卡点表 arc 的计划强度 0..1 | 动作幅度都乘它，起伏就出来了 |
| `M.events(kind)` | 时间数组 | 自己遍历 |

kind 可以是：`beat` 拍、`bar` 小节头、`kick` 底鼓、`snare` 军鼓、`hat` 镲、`line` 每句开唱、`char` 每个字、`shot` 换镜头、`moment` 所有时刻、`big` 大时刻，或者时间数组 `['bar9', 'bar13.3']`。

`pre: 0.5` = 事件前 0.5 秒开始蓄力（往上爬），`weight: true` = 乘以那一下的力度（底鼓有强有弱）。

## 卡点表里的时刻

- `M.hit('副歌炸开', {decay: .4, pre: .5})`：大时刻那一下 1，然后回落（pre 同上）；
- `M.after('副歌炸开')`：过了几秒（之前是负数），用来写「炸开以后 2 秒内碎片飞散」；
- `M.shot()`：当前镜头；`M.shots()`：全部；`M.moment(name)`：时刻对象。

## 歌词

运行库会按卡点表 `lyrics` 自动画歌词（见下面「上屏方式」），一般不用管。要在画面里自己画（字是画面的一部分，比如字写在气球上、刻在墙上），这句写 `"mode": "scene"`，然后：

- `M.line()`：现在唱的那句（`{n, text, t0, t1, sung_end, chars, hook}`），正好开唱那一刻才换；`M.lineN(8)`：第 8 句；
- `M.word(8, '灯火')`：第 8 句唱到「灯火」的时刻（秒）；卡点表里写 `line8@灯火`；
- `M.chars(line)`：每个字 `{c, t, age 唱过几秒, on 0..1 刚唱时的进场进度, sung}`；
- `M.sungText(line)`：已经唱到的字；
- `M.drawLine(ctx, 8, {mode: 'slam', pos: [960, 400], size: 'hero'})`：在你想要的地方用某种上屏方式画第 8 句（会自动记录，审片认得）；
- 完全自己画的，每帧调一次 `M.logLyric(n, 字号px, 透明度, 文本)`，不然审片会说这句没上屏。

## 氛围粒子

- `M.particles(ctx, name, {n, color, size, speed, alpha, seed, at, on, x, y, r, hue})`：纯函数。
  - 持续飘的：`embers` 火星、`dust` 风沙、`rain` 雨、`snow` 雪、`petals` 花瓣；
  - 一下炸开的：`fireworks` 烟花、`sparks` 火花，用 `at: 'line1@某个词'`（唱到那个字时炸）或 `on: 'bar'` 定时刻。

## 字

- `M.text(ctx, '文字', x, y, {size, font, fill, stroke, strokeW, align, rot, alpha})`：普通的字（标题、拟声词）；
- `M.measure('文字', {size, font})`：宽度；
- `M.glyph(ctx, 字, x, y, px, style)`：用歌词同款画一个字。

## 上屏方式（cues.json → lyrics）

| mode | 样子 | 适合 |
|---|---|---|
| `pop` | 唱到哪个字，哪个字弹出来 | 默认、主歌 |
| `slam` | 每个字从 2.5 倍大砸下来，带残影 | 铺垫、重拍密的句子 |
| `karaoke` | 整句先出（暗），唱到的字变亮、跳一下 | 抒情、长句 |
| `type` | 打字机 + 光标 | AI、聊天、电脑题材 |
| `chat` | 聊天气泡跟着打字长出来（左对齐） | 对话感 |
| `bubble` | 漫画对白泡泡，`tail: [x, y]` 指向说话的人 | 漫画、波普 |
| `stamp` | 整句一下盖上去（歪一点、带框） | 金句、口号 |
| `big` | 一句占满整个宽度，逐字砸 | 金句、副歌第一句 |
| `stack` | 正在唱的字占满画面（560px），唱过的排到底下 | 金句、慢一点的强调 |
| `scatter` | 字散在全屏各处，大小不一 | 副歌、热闹 |
| `wave` | 字跟着拍子上下浮 | 轻快、俏皮 |
| `scene` | 不自动画，scene.js 自己画 | 字是画面的一部分 |
| `none` | 不上屏（写 why） | |

样式字段（`lyrics.default`、`shots[].lyrics`、`lyrics.lines.lineN` 逐层覆盖）：

- 基本：`mode`、`size`（`hero` 210 / `big` 150 / `mid` 108，或像素数；太长会自动缩到画面里）、`pos`（`center` `lower` `upper` `left` `right` 或 `[x, y]`）；
- 颜色：`font`、`fill`、`stroke`、`strokeW`（字号的比例，默认 .09）、`shadow`（硬投影颜色）、`shadowOff`、`glow`、`dim`（karaoke 没唱到的颜色）；
- 底框：`box` / `boxFill` / `boxStroke`（给字垫底）、`frame: false`（stamp 不要框）、`tail`（bubble 尾巴）；
- 退场：`exit`（`fade` `cut` `up` `down` `zoom` `fall` `shatter` `squash`）、`exitDur`（秒）；
- 层：`layer`（`world` 跟镜头晃 / `screen` 不晃）。

## 特效（cues.json → moments[].fx / rules）

写字符串用默认值，写对象可以改参数：`{ "fx": "flash", "color": "#ff2d55", "amt": 1 }`。

| fx | 效果 | 参数（默认） |
|---|---|---|
| `flash` | 闪一下颜色 | amt .85，decay .14 秒，color #fff |
| `punch` | 镜头猛推进再弹回 | amt .08（推 8%），decay .32 |
| `shake` | 震动 | amt 22 像素，decay .4 |
| `rgb` | 红绿蓝错开（色散） | amt 16 像素，decay .3 |
| `zoomblur` | 往外冲的径向模糊 | amt .14，decay .32 |
| `tilt` | 镜头歪一下 | amt .06 弧度，decay .5 |
| `invert` | 反色一瞬 | dur .06 秒 |
| `strobe` | 反色频闪 | dur 1 拍，rate 1/8 拍 |
| `blackout` | 黑场 | dur 1（拍） |
| `glitch` | 横条错位 | amt 60 像素，dur .5 拍 |
| `ring` | 一圈冲击波 | decay .6，color，x / y |
| `speedlines` | 漫画速度线 | decay .5，color #000 |
| `stutter` | 画面卡带（时间反复跳回） | dur 1 拍，slice .25 拍 |
| `freeze` | 定格 | dur 1 拍 |
| `slowmo` | 慢放 | dur 2 拍，k .3 |
| `drift` | 慢慢推近（不回弹） | amt .03，decay 2 |

stutter / freeze / slowmo 只改镜头看到的时间，歌词和声音照常。rules 的特效默认按 arc 缩放（arc 低的地方自动变弱），不想缩放写 `"scale": false`。

## 转场（cues.json → shots[].in）

`cut`（默认）`fade` `flash` `whip-left/right/up/down`（甩镜头，带拖影）`push-left/…` `zoom`（冲进去）`iris`（圆形展开）`wipe`（斜切 + 色带，颜色用 look.accent）`glitch` `smash`（硬切 + 新画面猛缩回来）。

`inDur` 写拍数（默认 0.25–1 拍）。转场的正中间落在镜头的 at 上，所以那一拍看到的是转场最猛的那一下。

## 镜头运动

- 卡点表：`"cam": {"from": {"zoom": 1}, "to": {"zoom": 1.15, "x": -60}, "ease": "inOut3"}`，整个镜头内慢慢推、移（x、y 是像素，rot 是弧度）。
- scene.js：`camera(cam, M) { cam.zoom *= 1 + .02 * M.pulse('bar'); }`。
- 运行库会自动放大到不露黑边。

## 工具

- `M.ease`：`lin` `in2` `out2` `inOut2` `in3` `out3` `inOut3` `out5` `inOut5` `outExpo` `inExpo` `outBack(t, s)` `outElastic`；
- `M.clamp` `M.lerp` `M.smooth(a, b, x)` `M.hash(i, j)` `M.rng(seed)` `M.noise(x, y)` `M.TAU` `M.W` `M.H`；
- `M.cached(key, w, h, (g, canvas) => {...})`：画一次就缓存（静态底图、纹理、图案 tile），每帧只 `drawImage`；
- `M.layer(key)`：一张全屏离屏画布（每帧要自己清）；
- `M.fx`（当前帧特效强度，只读）、`M.cam`（当前镜头）、`M.song`（song.json）、`M.cues`（cues.json）、`M.img`。

## 性能（1080p 60 帧，45 秒 = 2700 帧）

- 静态的东西放进 `M.cached`，不要每帧重画几千个点。
- 不要每帧 `getImageData` / `putImageData` 全屏（慢几十倍）；网点、纹理用 `createPattern`。
- `ctx.filter = 'blur()'` 和大面积 `shadowBlur` 很慢，能用缓存的模糊图就用缓存的。
- 一帧超过 40ms 就慢了：`render.py stills` 看一下单帧耗时（跑得慢就是太重）。
